Conexão WhatsApp

API grátis ou API oficial:
você escolhe

Duas formas de conectar o WhatsApp ao CRM — com custo, risco e nível de suporte bem diferentes.

API grátis (não oficial)

Incluída
  • Conexão por QR code, usando o número que você já tem.
  • Sem custo por mensagem e ativação em minutos.
  • Ideal para começar rápido e validar a operação.
  • Não é homologada pela Meta: sujeita a bloqueio por uso inadequado, sem garantia oficial de estabilidade.

API oficial (WhatsApp Business)

Sob consulta
  • Número verificado e aprovado pela Meta.
  • Estabilidade, escala e recursos com suporte oficial.
  • Mensagens iniciadas pela empresa usam templates aprovados e têm custo por conversa.
  • Requer processo de verificação e um número dedicado.

Escolha conforme volume, tolerância a risco e orçamento — é possível migrar de uma para a outra.

Roteiro — API grátis x API oficial
  • API grátis: porta de entrada rápida, sem custo por mensagem, mas não homologada pela Meta — existe risco de bloqueio.
  • API oficial: para quem precisa de estabilidade, escala e conformidade; exige verificação na Meta e tem custo por conversa.
  • Não prometa aprovação da Meta nem prazo — é um processo externo ao produto.
Inteligência artificial

O bot qualifica. O humano fecha.

A IA não substitui o time — ela faz a triagem e entrega a conversa pronta para quem vende.

  • Score de qualificação — prioridade clara entre os leads.
  • Análise automática — resumo, pontos positivos, riscos e informações faltantes.
  • Próxima ação sugerida — o time sabe o que fazer a seguir.
  • Handoff humano — casos sensíveis ou complexos saem do bot.
  • Digest periódico — resumo dos leads por período, direto na rotina.
